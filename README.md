# Waveform Analyzer Pro

**Advanced FFT Spectrum Analyzer for oscilloscope CSV files.**

Features automatic Q-factor detection, Total Harmonic Distortion (THD), Fractal PSD analysis, and precise peak detection.

### Features
- Load oscilloscope CSV files (time + voltage)
- One-click automatic Q-factor measurement
- Total Harmonic Distortion (THD) calculation
- Fractal Power Spectral Density (PSD) with slope tools
- Automatic peak detection
- Multiple window functions and scale options
- High-resolution FFT analysis

### Educational Content
Includes rich educational materials and a complete step-by-step **Beginner's Guide** to help users understand FFT analysis, proper measurement techniques, and how to interpret results.

### How to Use
1. Export your signal from the oscilloscope as CSV
2. Open the tool in your browser
3. Load CSV file and enter sample rate
4. Analyze your signal
